# ✈️ 재팬플라이 (JapanFly) - 일본 항공권 실시간 최저가 비교 플랫폼

대한민국 주요 공항(인천, 김포, 부산, 대구, 청주, 제주)에서 도쿄, 오사카, 후쿠오카, 삿포로, 오키나와 등 일본 주요 도시로 가는 모든 항공권을 한눈에 비교하고 예약할 수 있는 웹 서비스입니다.

---

## 🌟 주요 특징 및 기능

1. **직관적인 검색 시스템 (Hero Search Bar)**
   - **출발지 / 도착지 선택 & 원클릭 반전**: 인천/김포/부산 등 국내 6대 공항 및 일본 주요 7개 공항 지원
   - **왕복 / 편도 및 일정 선택**
   - **인원 수 및 좌석 등급(일반석/비즈니스석) 설정**
   - **인기 급상승 퀵 필터 칩**: 클릭 한 번으로 도쿄, 오사카, 후쿠오카 등의 최저가 조회

2. **스마트한 가격 비교 & 필터링**
   - **7일간 최저가 캘린더 바**: 가장 저렴한 출발 날짜를 시각적으로 강조
   - **위탁 수하물 유무 필터링**: LCC 특가표 구매 시 낭패를 겪는 무료 위탁수하물(15kg~23kg) 포함 여부 완벽 분류
   - **항공사별 필터링**: 대한항공, 아시아나, 제주항공, 진에어, 티웨이, 에어부산, 에어서울, 피치항공, ANA, JAL
   - **소팅(정렬)**: 최저가순, 출발시간순, 최단비행시간순
   - **여행사별 가격비교 아코디언 드로어**: 트립닷컴, 공식 항공사, 아고다, 마이리얼트립, 하나투어 가격 비교

3. **인기 일본 여행지 큐레이션 및 추천**
   - 도쿄, 오사카, 후쿠오카, 삿포로 등 목적지별 최저가 및 매력 포인트 소개
   - 목적지 카드 클릭 시 바로 해당 노선 검색 연동

4. **특가 알림 신청 (CTA)**
   - 목표 가격대 오픈 시 이메일 알림을 수신할 수 있는 폼 제공

5. **완벽한 반응형 UI / UX**
   - PC, 태블릿, 모바일 모든 해상도에 최적화된 모던 에어라인 테마 디자인
