# ✈️ 재팬플라이 (JapanFly) - 일본 항공권 실시간 최저가 메타서치 플랫폼

**재팬플라이(JapanFly)**는 대한민국 주요 공항에서 출발하는 도쿄, 오사카, 후쿠오카, 삿포로 등 일본 전 노선의 항공권을 한 번의 검색으로 비교하고, **네이버 항공권 · 스카이스캐너 · 트립닷컴 · 구글 플라이트의 실시간 최저가 검색 결과로 즉시 연결(Deep Link)**해 주는 항공권 메타서치 웹 서비스입니다.

---

## 🌟 핵심 기능 및 특징

### 1. 🔗 실시간 딥링크 메타서치 엔진
- **서버 비용 0원 & 완전 무료 운영**: 고가의 항공 GDS API 없이 사용자가 입력한 조건(노선, 일정, 승객, 좌석 등급)을 파라미터로 조합하여 플랫폼별 실시간 검색 페이지로 직접 연결합니다.
- **국내외 4대 플랫폼 원클릭 비교**:
  - **네이버 항공권**: 국내 주요 여행사(하나투어, 모두투어, 노랑풍선 등) 실시간 최저가 통합 비교
  - **스카이스캐너(Skyscanner)**: 전 세계 저비용 항공사(LCC) 포함 글로벌 최저가
  - **트립닷컴(Trip.com)**: 일본 노선 특가 및 즉시할인 쿠폰 비교
  - **구글 플라이트(Google Flights)**: 캘린더별 가격 추적 및 변동 그래프 확인

### 2. 🔍 일본 특화 스마트 검색 & 필터
- **국내 6대 공항 출발 지원**: 인천(ICN), 김포(GMP), 김해/부산(PUS), 대구(TAE), 청주(CJJ), 제주(CJU)
- **일본 7대 인기 공항 지원**: 도쿄 나리타(NRT), 도쿄 하네다(HND), 오사카 간사이(KIX), 후쿠오카(FUK), 삿포로 신치토세(CTS), 오키나와 나하(OKA), 나고야 주부(NGO)
- **왕복 / 편도 및 인원/좌석 등급 설정**
- **인기 급상승 퀵 필터 칩**: 도쿄, 오사카, 후쿠오카 등 인기 도시 원클릭 최저가 조회
- **무료 위탁수하물 포함 필터**: LCC 특가표 구매 시 필수적인 무료 위탁수하물(15kg/23kg) 포함 여부 즉시 필터링
- **항공사 다중 필터링**: 대한항공, 아시아나항공, 제주항공, 진에어, 티웨이항공, 에어부산, 에어서울, 피치항공, ANA, JAL
- **정렬 옵션**: 최저가순, 출발시간순, 최단비행시간순

### 3. 📊 7일간 최저가 캘린더 스트립
- 선택한 노선 기준, 일주일간의 날짜별 최저가 및 가장 저렴한 요일을 시각적으로 한눈에 제공

### 4. 📱 모던 & 반응형 디자인
- PC, 태블릿, 모바일 모든 해상도에 최적화된 모던 에어라인 테마 UI
- 세련된 카드 레이아웃 및 플랫폼별 상세 비교 드로어 제공
